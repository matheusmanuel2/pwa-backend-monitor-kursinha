Como isso funciona

Tudo roda aqui no navegador, sem servidor. A checagem só acontece enquanto esta aba estiver aberta — se você fechar o navegador ou o computador desligar, o monitoramento para. No iPhone/Safari, notificações de site comum têm suporte limitado ou nenhum. A API bloqueia CORS, então detectamos apenas se ela está alcançável (timeout, DNS ou conexão recusada = "caiu"); um erro HTTP 4xx/5xx pode não ser detectado.
